# 🎭 Expression Extractor · 표정 추출기 (SillyTavern) 1.1.0

캐릭터 카드에서 외형을 읽고, Gemini로 감정별 표정 이미지를 만들어서 **SillyTavern 표정 스프라이트 폴더에 자동으로 저장**하는 확장이에요.
저장 위치는 `characters/<캐릭터 이름>/<감정>.png` (예: `characters/Mina/joy.png`)이라서 기본 *Character Expressions* 확장이 그대로 읽어요. 하나씩 업로드할 필요가 없어요.

## 설치
`SillyTavern/data/<유저>/extensions/expression-extractor/` 에 폴더째 넣거나 GitHub 주소로 설치 → 새로고침.
VN Studio가 있으면 API 키·제공자 설정을 처음 한 번 가져와요. (모델은 가져오지 않고 `gemini-3.1-flash-image` 기본값을 써요.)

## 사용
확장 설정 → **표정 추출기**에서 "사용"을 켜고 API 키를 넣어요. 마법봉 메뉴 → **표정 추출기** (또는 설정의 열기 버튼)
1. 캐릭터 선택 → 외형 태그 확인 (비워 두면 첫 생성 때 자동 추출)
2. 화풍·제외 요소 설정 (선택)
3. 만들 표정 선택 (기본 6 / 핵심 10 / 전체 28) → **선택한 표정 만들기**
4. neutral을 먼저 만들어 기준으로 삼고, 나머지는 한 장씩 천천히 생성 → 끝나는 즉시 스프라이트 폴더에 저장
5. ST 표정 확장은 채팅을 열 때 스프라이트 목록을 새로 읽어요. 바로 안 보이면 채팅을 다시 열어 주세요.

창은 **제목줄을 끌어서 옮기고, 오른쪽 아래 모서리를 끌어서 크기를 바꿀 수 있어요.** 위치와 크기는 저장돼요.

## 외형 태그 (장면 생성기 방식)
- 카드의 설명·성격 텍스트 → 텍스트 모델 → "영어 외형 태그 한 줄(45단어 이내)". 장면 생성기(Scene Studio)의 `appearanceOf`와 같은 프롬프트예요.
- 카드 설명이 안 바뀌면 저장된 태그를 다시 쓰고(해시), **직접 고치면 고정**돼요. "다시 추출" 버튼으로 새로 뽑을 수 있어요.
- 설정의 **텍스트 모델(연결 프로필)** 을 고르면 채팅 내용 없이 카드 설명만 그 모델로 보내요. 비우면 채팅에 연결된 모델을 써요.
- 예전(1.0)의 Gemini 이미지/텍스트 기반 추출은 완전히 제거했어요.

## 화풍 프롬프트 · 제외 요소 (장면 생성기 방식)
창의 "화풍 프롬프트 · 제외 요소"에서 프리셋을 저장/선택/삭제해요. "직접 입력"에 쓰고 이름을 정해 💾를 누르면 프리셋이 돼요. 제외 요소는 프롬프트 끝에 `Avoid: …`로 붙어요.

## 배경 제거 · 가장자리 조절
생성된 이미지는 흰 배경에서 가장자리부터 배경색만 지워 투명 PNG로 저장돼요. 투명해지지 않고 남는 가장자리는 아래 값으로 조절해요. (확장 설정에 기본값, 스프라이트의 ✂ 버튼에 미리보기 창)

| 값 | 하는 일 |
|---|---|
| 배경 민감도 (10~80) | 클수록 배경색과 덜 비슷해도 지워요 |
| 흰 테두리 제거 (0~100) | 인물 가장자리에 남은 흰/연한 띠를 3픽셀 깊이까지 지워요 |
| 가장자리 줄이기 (0~6px) | 경계를 안쪽으로 깎아요. 이미지 끝에 닿은 부분은 그대로예요 |
| 가장자리 부드럽게 (0~3px) | 경계를 흐리게 해서 계단을 줄여요 |

"배경 제거 전 원본도 보관"을 켜 두면(기본) 조절을 몇 번이든 **원본에서 다시 계산**해서 되돌릴 수 있어요. 원본은 `user/images/expression-extractor/`에 저장돼요.

## 참고
- 스프라이트 폴더는 캐릭터 이름이에요. ST 표정 확장의 "스프라이트 폴더 덮어쓰기"를 쓰면 그 경로를 따라가요.
- 키는 `settings.json`에 평문으로 저장돼요. 이미지 1장 = 이미지 API 1회 호출(요금 발생)이에요.
